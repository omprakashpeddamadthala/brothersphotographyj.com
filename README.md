# Brothers Photography

A modern, production-ready React application for a wedding photography studio. The site's
structure and interaction patterns are inspired by editorial photography portfolios (fullscreen
hero slideshow, masonry story galleries, lightbox, journal), built entirely with original copy
and royalty-free placeholder imagery so all assets can be swapped for your own.

## Tech Stack

- React 19 + TypeScript (strict) + Vite
- React Router (lazy routes, code splitting)
- Tailwind CSS v4
- Framer Motion (page transitions, scroll reveals, parallax) + GSAP available
- Lenis smooth scrolling
- Embla Carousel (testimonials)
- React Query + React Hook Form (contact enquiries)
- react-helmet-async (SEO: meta, OpenGraph, Twitter cards, JSON-LD)
- ESLint (oxlint) + Prettier + Husky + lint-staged

## Getting Started

```bash
npm install
npm run dev        # http://localhost:5173
```

## Folder Structure

```
src/
  components/
    common/    # SEO, LazyImage, Lightbox, MasonryGrid, ParallaxSection, Reveal, AnimatedHeading
    layout/    # Navbar (hide-on-scroll), Footer
    ui/        # Button (cva variants)
  data/        # Site config, stories, blog posts, placeholder image factory
  hooks/       # useLenis, useScrollDirection, useLockBodyScroll
  layouts/     # RootLayout (page transitions, Suspense, skip link)
  pages/       # Home, About, Stories, StoryDetail, Blog, BlogPost, Contact, 404
  sections/    # Hero, FeaturedStories, Testimonials, Awards, CallToAction, InstagramFeed
  services/    # Enquiry submission placeholder
  styles/      # Tailwind theme (fonts, palette)
  types/       # Shared TypeScript interfaces
  utils/       # cn, formatDate
```

## Routes

- `/` — hero slideshow, featured stories, testimonials, awards, CTA, Instagram grid
- `/about` — studio story and team
- `/stories` — masonry portfolio; `/stories/:slug` — full gallery with lightbox
- `/blog` — journal; `/blog/:slug` — article
- `/contact` — booking enquiry form
- `*` — 404

## Replacing Placeholder Images

All imagery is generated by `src/data/placeholders.ts` via picsum.photos. To use real photos:

1. Add files to `src/assets/images/` (or your CDN).
2. Update the `src` fields in `src/data/stories.ts`, `src/data/blog.ts` and the section files.
3. Keep `width`/`height` accurate — they drive aspect ratios and prevent layout shift.

## Customizing the Theme

Edit the `@theme` block in `src/styles/index.css`: fonts (`--font-serif`, `--font-sans`),
palette (`--color-ink`, `--color-paper`, `--color-mist`, `--color-stone`, `--color-gold`) and
letter-spacing. Fonts load from Google Fonts in `index.html`.

## Deployment

### Docker

```bash
docker compose up --build      # serves on http://localhost:8080
```

The multi-stage `Dockerfile` builds the app and serves `dist/` with Nginx
(`nginx/default.conf`: gzip, immutable asset caching, SPA fallback).

### Static Hosting

`npm run build` produces `dist/` — deploy to Netlify, Vercel, Cloudflare Pages, or S3+CloudFront.
Configure a SPA fallback to `index.html` for client-side routing.

### CI

`.github/workflows/ci.yml` lints, format-checks, type-checks, builds, uploads the bundle, and
verifies the Docker image on every push/PR.

## Accessibility & SEO

- Semantic HTML, skip link, ARIA labels, keyboard-navigable lightbox (Esc / arrows), visible focus states
- Respects `prefers-reduced-motion` (smooth scrolling disabled)
- Per-page meta via `SEO` component, JSON-LD on the homepage, `robots.txt` + `sitemap.xml`

## Assumptions

- The reference site's proprietary form backend is replaced by `src/services/enquiries.ts` — a
  placeholder that resolves locally; wire it to your provider.
- The Instagram feed is a static placeholder grid linking to the profile; swap in a real feed API
  if desired.
- Typekit fonts on the reference site are replaced with Google Fonts of similar character
  (Cormorant Garamond + Jost).
- All names, testimonials, awards and story copy are fictional placeholders.
